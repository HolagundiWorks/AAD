## Findings

### Files and code
- No duplicate, abandoned or unreferenced source files were found. Compiler warnings and
  `clippy -D warnings` are clean (checked in the baseline and in `cargo xtask ci`).
- Three declared dependencies had no use in the code of their crate and were removed after the
  workspace compiled without them (`cargo check --workspace --all-targets`): `cadcraft-render` in
  `cadcraft-cli`, `serde` in `cadcraft-agent`, `cadcraft-io` in `cadcraft-mcp`.
  All other dependencies, including target-specific ones (`rfd`, `sys-locale`, `winit`, `muda`,
  `wasm-bindgen`, `web-sys`, `eframe`, `acadrust`), are used.
- `crates/llm/Cargo.toml` mentioned a `--features assistant` flag that does not exist (the feature
  is `llama` on `cadcraft-llm`). Corrected.
- `xtask` messages and a comment point to `plan/architecture.md`; `/plan/` is git-ignored and does
  not exist. They now point to `docs/ARCHITECTURE.md`.
- `packaging/macos/dmg/generate.py` is Python; CLAUDE.md says "Rust only (no handwritten JS/TS)",
  which does not cover it. Kept (packaging for a later phase); flagged for the owner.
- macOS, Linux, Flatpak and web packaging (about 25 files) are not part of the Windows-only scope but
  are intentionally kept for the later phases and are not deleted.

### Documentation
- `docs/architecture.md` was out of date (12 crates instead of 13, 320 engine commands instead of
  339, no `llm`, no DWG worker, no threading or undo section). Rewritten in place and renamed to
  `docs/ARCHITECTURE.md`.
- `docs/BUG_BACKLOG.md` linked to a `QUALITY_AUDIT.md` that was never written. Link corrected.
- `docs/UI_INVENTORY.md` gave the registry total (385) as engine commands. Corrected to 339 + 46.
- Documents added: `PROJECT_STRUCTURE`, `BUILD_AND_DEVELOPMENT`, `CAD_ENGINE`, `UI_UX`,
  `RELEASE_AND_PACKAGING`, `KNOWN_ISSUES`, this audit and the cleanup report. `TESTING_STRATEGY` was
  renamed `TESTING` and `PERFORMANCE_BASELINE` `PERFORMANCE`, matching the requested names.
- `docs/parity-checklist.md` is generated (`cargo xtask parity`) and untouched.
- The release process (`docs/releasing.md`) describes signing secrets and CI jobs that were not
  verified here.

### Hygiene
- `.gitignore` already ignores `/target`, `/dist/`, `/log/`, `/temp/`, `/plan/`, `/plans/`. No
  tracked file is inside an ignored folder. `*.profraw`, `*.profdata`, `/coverage/` and `/build/`
  are not needed: no such output is produced by any script.
- `target/` reached 101 GB. After the cleanup, a complete rebuild (the full `cargo xtask ci` plus `cargo build --workspace --release`) came to 25 GB, so about 75 GB was stale accumulated output. Still large by nature: every dependency is compiled at
  `opt-level = 2` in the debug profile and each of the 148 test binaries is linked separately. A trade-off
  for the owner, not changed here.
