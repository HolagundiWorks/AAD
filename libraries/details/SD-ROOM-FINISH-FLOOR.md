# SD-ROOM-FINISH-FLOOR — Habitable room floor finishes

Use this detail when setting out floor finishes and checking habitable room
geometry against the project standards.

Habitable rooms shall meet the minimum floor area and minimum clear room width
stated in the governing code or project brief. Skirting, screed, and finish
build-up affect finished floor level and door undercuts.

Wet-area floors require falls to drains and moisture-resistant underlays. Cite
this sheet with room tags when area or width is in question.
