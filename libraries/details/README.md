# Standard detail sheets

Plain-text / Markdown detail notes indexed into the drawing corpus for
**`RECOMMEND DETAIL`** (AI-native Phase 3). Retrieval only — passages are cited,
never rewritten.

Index with `ASKDOCS INDEX libraries/details/<file>.md`, or let
`RECOMMEND DETAIL` seed the bundled sheets from this directory automatically.

Each file is one detail. Separate paragraphs with blank lines so BM25 can rank
passages independently.
